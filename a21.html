🧠 Ana Mantık: “Presentenin Geçmişi”

Presente’de ne yapıyorsak / nasılsak / nerede isek, Imperfecto ile bunu geçmişte “-yordum / -rdım / idi” mantığına taşırız.
1. Tekrar eden geçmiş eylem
De niño jugaba en la calle.
Çocukken sokakta oynardım.
2. Geçmişin tarifi / arka planı
La casa era grande.
Ev büyüktü.
3. “-idi” / durum anlatımı
Estaba cansada.
Yorgundum.

🔮 Ir a + Infinitivo → Imperfecto

Presente
Voy a decir la verdad.
Gerçeği söyleyeceğim.
Imperfecto
Iba a decir la verdad.
Gerçeği söyleyecektim.
🧠 voy a + infinitivo → iba a + infinitivo = “-acaktım / -ecektim”

🏃 Estar + Gerundio → Imperfecto

Presente
Estoy bailando.
Dans ediyorum.
Imperfecto
Estaba bailando.
Dans ediyordum.
🧠 estoy + gerundio → estaba + gerundio = “-yordum”

📌 Sıralama

OI + OD + FİİL
Cindy compró una gorra para mí.

Ne aldı? → una gorra = OD
Kimin için? → para mí = OI

Cindy me la compró.
Cindy onu benim için aldı.
Le doy el libro.

le = ona · el libro = onu

Se lo doy.
Onu ona veriyorum.

📍 OD + OI Cümlede Nereye Yerleşir?

Önce sıra değişmez: OI + OD
Örn. te + lo, me + la, se + los
1. Sadece çekimli fiil varsa

Zamirler fiilin önüne gelir.

Te lo compro.
Onu sana alıyorum.

Se la doy.
Onu ona veriyorum.
2. Fiil grubunda MASTAR varsa

İki doğru yerleşim vardır.

Te lo voy a comprar. ✅
Voy a comprártelo. ✅

Onu sana alacağım.
Mastara bağlanınca zamirler sona eklenir ve vurgu korunması için tilde gerekebilir: comprar → comprártelo
3. Fiil grubunda GERUNDIO varsa

Yine iki doğru yerleşim vardır.

Te lo estoy comprando. ✅
Estoy comprándotelo. ✅

Onu sana satın alıyorum.
Gerundioya bağlanınca tildeyi unutma: comprando → comprándotelo
4. Olumlu IMPERATIVO varsa

Zamirler fiilin sonuna bitişik gelir.

¡Cómpratelo! ✅
Onu kendine / onu satın al!

¡Dámelo! ✅
Onu bana ver!
Bu yapıda zamirleri fiilin önüne koymayız.
🧠 Hızlı karar:
Çekimli fiil tek başına → ÖNDE
Mastar / gerundio varsa → ÖNDE veya SONA BİTİŞİK
Olumlu imperativo → SONA BİTİŞİK
